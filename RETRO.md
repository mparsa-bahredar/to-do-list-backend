Stage 2

1- What happens if you POST without a title?
The API should return 400 Bad Request because the title is required.

2- Should the ID be generated by the client or the server? Why?
The server should generate the ID to keep IDs unique and consistent.

3- What happens when you delete a task that doesn't exist?
The API returns 404 Not Found because the task does not exist.


Stage 3

4- How does Express decide which handler responds to a request?
Express checks the middleware and routes in the order they are defined.

5- What happens if a requested static file does not exist?
express.static() passes the request to the next middleware or route.

6- Should the uploads folder be publicly listable?
No. Users should not be able to see all uploaded filenames.

7- What does this mean for how you name files?
File names should not contain sensitive information or be easy to guess.
